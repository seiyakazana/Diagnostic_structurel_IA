- (capability) CAP-5 Compliant PDF deliverable — assemble all survey data + annotated photos into a chosen configurable template (visit report / full diagnostic / unit disorder sheet) with regulatory layout (cover, auto TOC, pagination, per-zone synthesis) and export/share (local, email, secure link), generable offline. success: PDF contains all captured data + >=1 relevant coupe + annotated schema + disorder mapping consistent with numbering + correct layout; readable at any photo/schema volume.
- (capability) CAP-6 Technical coupes — expert selects from a preconfigured coupe library (wall, floor, foundation, roof, post-beam) and positions surveyed disorders on it. success: >=1 relevant coupe with positioned disorders embedded; positions match survey numbering.

- (capability) CAP-8 Automatic disorder mapping — numbered survey disorder points auto-reported onto the selected coupe/schema, each cross-referenced to its fiche de desordre. success: mapping is consistent with survey numbering and each point links to the correct disorder sheet.
- (capability) CAP-9 AI disorder detection and classification — 6 categories (fissuration, corrosion/carbonatation, humidite/infiltrations, deformations, maconnerie, degradations diverses), bbox/mask localization, severity (leger/modere/severe/critique), confidence %. success: >75% accuracy on cracks and corrosion on the test set with confidence shown per detection; other categories best-effort.
- (capability) CAP-10 Expert validation loop — expert validates/corrects/rejects each AI detection and manually adds missed disorders (AI proposes, expert disposes). success: each result actioned in <5s; every validated correction stored as training data.
- (capability) CAP-11 Structured disorder database — store images+annotations, classify by structure type/disorder/severity/geolocation, full traceability (expert, date, mission, ouvrage), export datasets. success: datasets exportable for retraining with complete traceability.
- (capability) CAP-12 Continuous learning loop — collect -> annotate -> retrain -> validate -> deploy cycle over validated corrections. success: validated corrections feed a dataset that retrains the model, gated on test-set performance before deployment.
- (capability) CAP-13 AI performance dashboard — precision/recall/F1 per disorder category, model version history and comparison, performance-drift alerts. success: per-category metrics and cross-version comparison are visible; an alert fires on detected drift.
